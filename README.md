# Realistic Water Android Mali

This mod allows you to use the **Realistic Water** mod on devices with Mali GPUs.

## How to install

1. Download and install Fabric: [Fabric installation guide](https://docs.fabricmc.net/players/installing-fabric/)
2. Download the original Realistic Water mod by [sskaffy](https://github.com/sskaffy/Realistic-Water).
3. Download the [Realistic Water Android mod](https://github.com/khangtan959-bot/realistic-water-android).
4. Download this mod.
5. Place all three mod files into your `mods` folder.
